在基础流水灯之上增加按键控制:按下板载按键 KEY1,流水灯流向立即反转。

## 硬件

- 主控:STM32F103C8T6(KEYSKING STM32_KIT 学习板)
- 4 × LED + 4 × 限流电阻(220Ω~470Ω)
- 面包板 + 公对母杜邦线
- 板载按键 KEY1

## 引脚连接

| 引脚 | 功能 | 说明 |
| --- | --- | --- |
| PA12 | LED1 | 外接 |
| PA15 | LED2 | 外接 |
| PB3 | LED3 | 外接 |
| PB1 | LED4 | 外接 |
| PB12 | KEY1 按键 | 板载,外部中断输入 |

## 软件

- STM32CubeMX 6.17 + STM32CubeIDE 2.1.1(HAL 库)
- 按键采用 EXTI12 外部中断:下降沿触发 + 内部上拉
- 消抖:两次有效按键间隔大于 200 ms
- 方向切换:`dir = -dir`;位置循环:`(pos + dir + 4) % 4`
